# 小王子 · B-612

一个完全离线、单文件运行的 Three.js 互动场景：B-612 小行星、红玫瑰、狐狸，以及围绕它松散分布六颗故事星球——国王、爱虚荣的人、酒鬼、商人、点灯人、地理学家。固定黄昏、暖星、无失败、无进度条。

## 在线访问

- Vercel：<https://little-prince-b612.vercel.app/>
- GitHub Pages：<https://YI260602.github.io/little-prince-b612/>
- 本地：直接双击 `index.html` 即可打开，不需要服务器或网络。

## 操作

- `W A S D` / 方向键：走一走
- `空格`：轻轻飘起；按住 `W` 可以飞向远方的星球
- 按住拖动：看四周（开场遮罩期间也可以拖动）
- 滚轮：拉近拉远；`Q` / `E`：备用旋转视角
- 靠近玫瑰、狐狸或故事星球上的人物，会自动出现台词；在狐狸旁边安静待一会儿，它会慢慢靠近你

## 技术

- Three.js r159（内联，无 CDN）
- 单文件自包含：模型、贴图、天空、粒子、后期全部程序化生成
- 离线可运行，无外部请求
